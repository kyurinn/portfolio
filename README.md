## 🏛️ Overview & Architecture

Personal engineering portfolio showcasing verified production systems, low-level architecture, and applied AI pipelines. Built with zero runtime bloat, high-performance WebGL, and accessible semantic HTML.

### Tech Stack:
- **Core:** Semantic HTML5, CSS3 Variables, Vanilla ES6+ JavaScript.
- **3D Visualization:** Three.js (r128) + UnrealBloomPass post-processing (Cybernetic Geodesic Polyhedral Core with gyroscopic orbital rings).
- **Typography:** Cormorant Garamond (Editorial Serif), Hanken Grotesk (Humanist Sans), JetBrains Mono (Technical Monospace).
- **Deployment:** Vercel Continuous Delivery with Edge CDN.
